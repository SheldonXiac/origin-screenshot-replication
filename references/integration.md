# Integrated upstream skills

This skill can work alongside the following upstream packages. They are separate projects and are not bundled here; consult each repository for its current license and installation instructions:

- [`originplot`](https://github.com/peterbruce716-art/originplot-skill): semantic table inspection, FigureSpec/OperationPlan compilation, capability checks, and save/reopen verification.
- [`python-origin-plotting`](https://github.com/Gerry2024-hub/Gerry2024-hub-python-origin-plotting-skill): Windows `originpro` workbook/graph construction, export, and OPJU handling templates.

Use the upstream contracts instead of copying their whole implementation into this skill. The screenshot route supplies the missing image analysis, pixel calibration, and reference-image QA. Any result recovered from pixels must keep its provenance and uncertainty labels.
